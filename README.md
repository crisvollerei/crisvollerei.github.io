# 清蒸排班表

本项目的开发过程中使用了AI工具辅助实现，提升了开发效率。

一个功能强大、视觉美观的排班日历应用，支持自定义班次、周期、预设方案，提供丰富的统计与可视化功能，完美适配移动端和桌面端，纯前端实现无需后端依赖。

## ✨ 功能特点

- 🎨 **双主题切换**：支持暗黑模式（默认）和亮色模式，自动记忆用户偏好
- 📅 **今日班次动态展示**：直观显示今日排班、周期进度、实时上下班倒计时、距离最近休息日
- 📆 **完整日历视图**：按月查看排班，支持月份切换、快速回到今日，点击日期查看详情
- ⚙️ **高度自定义**：
  - 锚定日期与周期模式可自由配置
  - **每个班次独立定义**：名称、图标、上下班时间、是否跨日、是否工作班次
  - 所有配置自动本地保存
- 🎯 **预设方案系统**：
  - 一键保存当前完整配置（含周期、班次定义）为预设
  - 快速切换不同排班方案（如标准三班倒、夜班季等）
  - 预设列表带有删除功能，管理方便
- 📊 **智能统计面板**：
  - 本月各类型班次数量及环比趋势
  - 本月累计工时
  - 环形图展示本月班次占比
  - 年度排班热力图，点击月份可快速跳转
- 🎉 **法定节假日标记**：完整标注中国法定节假日（2025-2030年数据）
- 🗓️ **农历显示**：同时显示阳历和农历日期，初一显示月份
- 🌱 **二十四节气**：标注完整的24节气，配有对应emoji图标
- 🔍 **日期详情面板**：点击任意日期查看该日排班、周期位置、连续同班天数、距休息日天数等
- ⏱️ **实时时钟与倒计时**：显示当前时间，自动计算距离上班/下班的时间
- 📱 **响应式设计**：完美适配手机、平板、桌面等各种设备尺寸
- ⚡ **性能优化**：原生JS实现，轻量无框架，加载快速
- ⌨️ **键盘快捷键**：←/→ 切换月份，T 回到今天，Esc 关闭面板

## 🚀 使用方法

### 1. 获取文件
直接下载 `index.html` 即可使用。

### 2. 直接使用
无需安装依赖，直接用浏览器打开该文件即可。

### 3. 自定义排班设置
点击页面底部的「⚙️ 排班设置」按钮，可配置：
- **锚定日期**：排班周期的起始参考日期（格式：YYYY-MM-DD）
- **周期模式**：用空格分隔的排班序列，例如：`白班 夜班 休息 白班 夜班 休息 休息 休息`
- **班次时间定义**：为周期中的每个班次单独设置：
  - 上班/下班时间（支持跨日）
  - 是否工作班次
  - 预设样式（白班/夜班/休息/中午/早班/晚班）
  - 可添加新班次或删除已有定义

配置完成后会自动保存到本地存储，刷新页面不会丢失。

### 4. 使用预设方案
- 点击右上角「+」按钮，可将当前配置保存为预设（需命名）
- 预设按钮会显示在右上角，点击即可一键应用该方案
- 悬停预设按钮可出现删除图标，管理方便

### 5. 查看排班详情
- 在日历中点击任意日期，左侧（桌面）或下方（移动）会显示该日详细排班信息
- 年度热力图可点击月份快速跳转

## 🛠️ 技术栈

- **HTML5**：语义化标签，结构化布局
- **CSS3**：
  - CSS变量实现主题切换
  - 玻璃态（Glassmorphism）设计语言
  - 渐变、阴影、动画提升视觉体验
  - Grid/Flex 布局实现响应式
- **JavaScript (ES6+)**：
  - 原生JS实现所有交互逻辑
  - LocalStorage 本地存储配置
  - 日期处理与计算（含农历转换和节气算法）
  - 实时时钟与倒计时更新
- 字体：Noto Sans SC (中文)、JetBrains Mono (等宽字体)
- 图标：Font Awesome 6（免费版）

## 🎨 自定义扩展

### 1. 修改班次预设样式
代码中 `CSS_PRESETS` 和 `PRESET_COLORS` 定义了六种预设样式（day/night/rest/noon/morning/evening），可修改对应颜色。

### 2. 添加更多节假日
修改代码中 `HOLIDAYS` 常量，格式：
```javascript
const HOLIDAYS = {
  '2026-01-01': '元旦',
  '2026-02-17': '春节',
  // 添加更多节假日...
};
```

### 3. 扩展节气数据
修改代码中 `SOLAR_TERM_DATES` 常量，目前已包含2025-2030年数据。

### 4. 修改主题配色
修改CSS中 `:root` 和 `[data-theme="light"]` 下的CSS变量。

### 5. 更换头像
替换代码中 `avatar.png` 为自定义头像图片，或修改头像 fallback 文字。

## 💡 提示

- 所有配置数据存储在浏览器本地存储中，清除浏览器数据会导致配置丢失
- 预设方案会保存完整的周期、锚定日期和班次定义，方便快速切换
- 建议将文件保存到本地或部署到静态托管服务（如GitHub Pages、Netlify）使用
- 如需适配更多设备，可调整CSS中的响应式断点和样式
- 节假日和节气数据可根据国务院发布的最新安排进行更新
- 班次时间定义中的“跨日”选项适用于夜班等跨越午夜的情况，会自动计算下班时间
