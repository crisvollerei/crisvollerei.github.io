# 清蒸排班表

一个完全在浏览器中运行的个人轮班日历。支持自定义周期、班次时间、跨日班、方案切换、月度统计和年度总览，不需要后端服务。

当前界面采用「银昼 / 蓝夜」两套完整的插画手札主题。银昼以银白人物、冰晶、银翼圆环和珍珠边饰组成「银翼手札」；蓝夜以蓝发人物、月相、星图、海浪、尾鳍和蕾丝组成「深蓝夜航」。保留顶部立绘，并分别配有大肥龙 / 大肥鱼的 Q 版小陪伴角，月历、统计和设置保持清晰可操作。详见 `DESIGN_NOTES.md`。

主题同时覆盖背景、字体、卡片、按钮、进度饰扣、日期徽章与弹窗。顶部场景与排班工具栏分层排布，窄屏自动缩小人物和装饰。插画、PNG 人物与 SVG 装饰全部保存在本地，不增加外部依赖。

## 使用

下载整个项目后，直接打开 `index.html`。请保留它旁边的 `assets/` 文件夹和 `avatar.png`，页面运行时不依赖外部字体、图标或 CDN。

也可以安装 Node.js 22.13 或更新版本后，在项目目录运行：

```sh
npm start
```

在浏览器中访问终端显示的本机地址，默认是 `http://127.0.0.1:4175`。预览服务仅允许读取首页、头像及前端资源。直接打开文件和使用本机预览地址属于不同的浏览器存储空间；已有线上网站的数据也不会自动出现在本机地址。

## 排班与方案

- 点击「排班设置」，选择周期起始日期，再用空格填写重复的班次顺序，例如 `白班 夜班 休息 白班 夜班 休息 休息 休息`。起始日期对应第一个班次。
- 每个班次可以设置颜色、工作或休息属性，以及上下班时间。名称不能包含空格，最多 40 个字符。
- 下班时间早于或等于上班时间时，视为次日下班。也可以手动勾选「跨日」；例如 09:00 至次日 17:00 会计为 32 小时。
- 修改期间使用独立草稿；「取消」、关闭弹窗或按 Esc 都会放弃修改。添加、删除班次不会丢失其他尚未保存的输入。
- 在周期中直接输入新名称时，第一次保存会补充对应的时间定义，确认后再次保存才会应用。
- 「保存方案」会打开页面内的命名窗口，确认后记录当前周期起始日期、周期和班次定义，不再依赖部分应用内浏览器可能禁用的系统输入框。空名称、超长名称或重名会在窗口内提示；取消、关闭或按 Esc 不保存。顶部方案按钮用于切换，旁边的 × 用于删除方案；删除方案保留当前排班。
- 日历显示班次名称、农历及节气，点击日期可查看详细安排。年度总览可以点击月份跳转，点击其中的小日期也可以打开详情。
- 侧栏显示未来七天；选中日期后，侧栏切换为该日详情，关闭后恢复七天安排。年度总览默认折叠，可通过顶部「年度总览」或页面下方的展开入口查看。
- 月度统计跟随当前查看的月份；计划工时按班次开始日期计入当月，保留小数，不等同于考勤记录或工资核算。
- 仍在进行的昨日跨日班次会显示「昨日班次」，周期位置随实际班次起始日期计算；到达下班时间后自动切换。

键盘：← / → 切换月份，T 回到今天，Esc 关闭弹窗或详情。年月范围为当前年份前后各一年，按钮和快捷键使用同一边界。

顶部月亮 / 太阳按钮用于手动切换主题，旁边的时钟按钮启用昼夜自动模式：设备本地时间 07:00–19:00 为银昼，其余时间为蓝夜。已有手动偏好会保留，自动模式也会被记住。首次绘制前就应用主题，避免深色页面闪白。

切月、日期详情、弹窗和年度展开有轻量过渡。顶部有缓慢旋转的饰环、上下浮动的冰晶或气泡，以及低频的人物和星点动效；蓝夜页脚水波缓慢移动。系统设置了「减少动态效果」时，装饰动画和移动过渡均关闭，功能保持可用。

## Q 版小陪伴

- 银昼显示用户提供的银白大肥龙，文案使用灰紫色；蓝夜显示深蓝大肥鱼，文案使用雾蓝色。原图保留透明通道，不替换顶部立绘。
- 点击人物，在该角色的六条轻松短句和当前排班的一条简要信息之间交替切换。短句打乱顺序，一轮内不重复；不会自动轮播或弹出通知。
- 排班提示包括距离下班、距离下次上班、明天的班次与开工时间、距离下个休息日等，每次只说一条。倒计时显示到分钟，不到一分钟时明确标注；时间分别用青蓝 / 暖金色加粗。
- 信息与当前配置、切换后的方案、实际日期和上下班边界同步，昨日跨日班结束前仍按该班计算。查看其他月份不改变实时提示。纯休息周期不会编造下次上班时间。
- 常规桌面为月历旁的独立小角落；手机与平板放在月历上方。只有宽度至少 2070 px、且高度至少 600 px 的屏幕，才放入页面右下方空白边缘悬浮，不遮挡内容。可用「收起 / 聊两句」折叠气泡，再点人物也能展开。
- 人物点击时轻弹并闪出小星光，支持 Enter / Space。开启减少动态效果后不播放这些动画。自动倒计时不会反复打断屏幕阅读器。

## 本地数据

配置和方案只保存在当前浏览器、当前站点的本地存储中，不上传到服务器，也没有账号或设备同步。清除站点数据会清除这些配置。浏览器禁止存储或容量不足时，页面会明确提示，此时仍能在当前会话中使用。页面内命名窗口能避开原生输入弹窗限制，但不能绕过宿主应用对本地存储的禁用或清理；这种情况下不会将临时保存误报为持久保存成功。

新版读取旧版的 `qingzheng-anchor`、`qingzheng-cycle`、`qingzheng-shift-defs` 和 `qingzheng-presets`。保存排班后使用单条 `qingzheng-config` 记录，避免分次写入造成部分保存。旧的配置键保留，不主动删除。损坏的 JSON、空周期或无效日期不会阻止页面启动。

## 农历、节气和节日

2025–2030 年农历月首和 144 个节气日期来自[香港天文台公历与农历对照表](https://www.hko.gov.hk/sc/gts/time/conversion.htm)，离线存放在 `assets/calendar-data.js`。日期按 UTC+8 的中国历法理解，并按年使用对应的表，不会拿 2026 年的节气日期代替其他年份。

已覆盖年份使用月首表推导农历，避免不同浏览器内置历法对 2027 年春节等日期的计算差异。超出覆盖年份时，农历使用浏览器的 Chinese Calendar 支持作为回退，未另行逐日核验；没有对应年份数据的节气不显示。

节日标记仅显示节日本身的日期，不推测未来法定假期、连休或调休安排。实际工作和休息始终由用户设置的排班周期决定。

日期格会以彩色标签和小插画标出元旦、除夕、春节、元宵节、清明、劳动节、端午节、中秋节、国庆节、重阳节：对应庆祝礼花、饺子、灯笼与梅花、花灯与汤圆、柳枝与风筝、齿轮与麦穗、粽叶、月兔与月饼、旗帜、菊花与远山。插画采用细描边与柔和配色，两套主题共用同一组素材和节日颜色。

当天为节日时，今日概览增加节日提示；点击节日日期也可在详情中看到完整名称和插画。同一天遇到两个节日时会保留两者。提示按设备当前日期切换，昨日跨日班次不会影响当天的节日判断。

「未来七天」同样显示对应日期的节日名称和小插画，节日标签放在日期与班次下方；与月历共用历法判断和插画配色，跨月、跨年及午夜更新时保持一致。点击该行仍会打开当天排班详情。

全站功能文字较前版放大，日期格同时增加高度。手机日期格把日期、班次、农历、插画、节日名称分行排布；节日名称允许换行，避免小屏截断。

## 项目结构

```text
index.html                 页面结构
avatar.png                 原有品牌头像
assets/styles.css          明暗主题与响应式样式
assets/themes.css          服饰纹样、边框、饰扣和主题细节
assets/festivals.css       节日共享配色、卡片插画布局与字号调整
assets/companion.css       Q 版陪伴气泡、点击反馈与响应式避让
assets/silver-atrium.svg   银翼圆环、拱廊与冰晶场景
assets/tidal-observatory.svg 月相、星图、海浪与尾鳍场景
assets/app.js              页面交互、草稿、存储和视图
assets/schedule-core.js    配置校验与日期、班次计算
assets/calendar-data.js    已核验的农历月首和节气数据
assets/character-day.webp 银昼人物透明素材
assets/character-night.webp 蓝夜人物透明素材
assets/chibi-day.png       用户提供的大肥龙 Q 版原图
assets/chibi-night.png     用户提供的大肥鱼 Q 版原图
scripts/serve.mjs          无依赖的本机预览服务
tests/                    计算与交互回归测试
wrangler.jsonc             原有 Cloudflare 静态托管配置
.assetsignore             防止测试和本地备份被打包为网站资源
```

网站运行不需要安装依赖。开发测试使用 JSDOM：

```sh
npm ci
npm test
```
