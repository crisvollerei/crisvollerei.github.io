# 清蒸排班表

一个完全在浏览器中运行的个人轮班日历。支持自定义周期、班次时间、跨日班、方案切换、月度统计和年度总览，不需要后端服务。

## 使用

下载整个项目后，直接打开 `index.html`。请保留它旁边的 `assets/` 文件夹和 `avatar.png`，页面运行时不依赖外部字体、图标或 CDN。

也可以安装 Node.js 22.13 或更新版本后，在项目目录运行：

```sh
npm start
```

在浏览器中访问终端显示的本机地址，默认是 `http://127.0.0.1:4175`。预览服务仅允许读取首页、头像及前端资源。直接打开文件和使用本机预览地址属于不同的浏览器存储空间；已有线上网站的数据也不会自动出现在本机地址。

## 排班与方案

- 点击「排班设置」，选择周期起始日期，再用空格填写重复的班次顺序，例如 `白班 夜班 休息 白班 夜班 休息 休息 休息`。起始日期对应第一个班次。
- 每个班次可以设置颜色、工作或休息属性，以及上下班时间。名称不能包含空格，最多 40 个字符。
- 下班时间早于或等于上班时间时，视为次日下班。也可以手动勾选「跨日」；例如 09:00 至次日 17:00 会计为 32 小时。
- 修改期间使用独立草稿；「取消」、关闭弹窗或按 Esc 都会放弃修改。添加、删除班次不会丢失其他尚未保存的输入。
- 在周期中直接输入新名称时，第一次保存会补充对应的时间定义，确认后再次保存才会应用。
- 「保存方案」会记录当前日期、周期和班次定义。顶部方案按钮用于切换，旁边的 × 用于删除方案；删除方案保留当前排班。
- 日历显示班次名称、农历及节气，点击日期可查看详细安排。年度总览可以点击月份跳转，点击其中的小日期也可以打开详情。
- 月度统计跟随当前查看的月份；计划工时按班次开始日期计入当月，保留小数，不等同于考勤记录或工资核算。
- 仍在进行的昨日跨日班次会显示「昨日班次」，周期位置随实际班次起始日期计算；到达下班时间后自动切换。

键盘：← / → 切换月份，T 回到今天，Esc 关闭弹窗或详情。年月范围为当前年份前后各一年，按钮和快捷键使用同一边界。

## 本地数据

配置和方案只保存在当前浏览器、当前站点的本地存储中，不上传到服务器，也没有账号或设备同步。清除站点数据会清除这些配置。浏览器禁止存储或容量不足时，页面会明确提示，此时仍能在当前会话中使用。

新版读取旧版的 `qingzheng-anchor`、`qingzheng-cycle`、`qingzheng-shift-defs` 和 `qingzheng-presets`。保存排班后使用单条 `qingzheng-config` 记录，避免分次写入造成部分保存。旧的配置键保留，不主动删除。损坏的 JSON、空周期或无效日期不会阻止页面启动。

## 农历、节气和节日

2025–2030 年农历月首和 144 个节气日期来自[香港天文台公历与农历对照表](https://www.hko.gov.hk/sc/gts/time/conversion.htm)，离线存放在 `assets/calendar-data.js`。日期按 UTC+8 的中国历法理解，并按年使用对应的表，不会拿 2026 年的节气日期代替其他年份。

已覆盖年份使用月首表推导农历，避免不同浏览器内置历法对 2027 年春节等日期的计算差异。超出覆盖年份时，农历使用浏览器的 Chinese Calendar 支持作为回退，未另行逐日核验；没有对应年份数据的节气不显示。

节日标记仅显示节日本身的日期，不推测未来法定假期、连休或调休安排。实际工作和休息始终由用户设置的排班周期决定。

## 项目结构

```text
index.html                 页面结构
avatar.png                 原有品牌头像
assets/styles.css          明暗主题与响应式样式
assets/app.js              页面交互、草稿、存储和视图
assets/schedule-core.js    配置校验与日期、班次计算
assets/calendar-data.js    已核验的农历月首和节气数据
scripts/serve.mjs          无依赖的本机预览服务
tests/                    计算与交互回归测试
wrangler.jsonc             原有 Cloudflare 静态托管配置
.assetsignore             防止测试和本地备份被打包为网站资源
```

网站运行不需要安装依赖。开发测试使用 JSDOM：

```sh
npm ci
npm test
```

测试覆盖坏配置恢复、旧配置兼容、草稿取消、输入校验、自定义名称安全、完整周期搜索、跨午夜更新、跨日工时、方案切换、日期边界和弹窗焦点等。
