# 清蒸排班表

一个完全在浏览器中运行的个人轮班日历。支持自定义周期、班次时间、跨日班、方案切换、月度统计和年度总览，不需要后端服务。

当前界面采用「银昼 / 蓝夜」两套完整的插画手札主题。银昼以银白人物、冰晶、银翼圆环和珍珠边饰组成「银翼手札」；蓝夜以蓝发人物、月相、星图、海浪、尾鳍和蕾丝组成「深蓝夜航」。保留顶部立绘，并分别配有大肥龙 / 大肥鱼的 Q 版小陪伴角，月历、统计和设置保持清晰可操作。详见 `DESIGN_NOTES.md`。

主题同时覆盖背景、字体、卡片、按钮、进度饰扣、日期徽章与弹窗。顶部场景与排班工具栏分层排布，窄屏自动缩小人物和装饰。插画、WebP 人物与 SVG 装饰全部保存在本地，不增加外部依赖；原始 PNG 另行保留。

## 使用

### 单文件离线版：双击即用

直接双击项目根目录的 **`qingzheng-offline.html`**，使用较新的 Edge、Chrome、Firefox 或 Safari 打开。脚本、样式、头像、双主题人物和 SVG 装饰全部包含在这一个文件里，可以单独复制到其他文件夹或 U 盘；不需要安装 Node.js，不需要启动服务器，也不需要联网。当前文件约 0.63 MB。

离线版与网站版共用同一套源码和交互，包含设置、方案、本地存储与主题切换。离线版生成时将模块连接为私有作用域内的普通脚本，保留模块边界，不要求浏览器在 `file://` 下加载外部模块；CSP 只放行本文件对应的脚本和样式哈希，不开放任意内联脚本或 `eval`。

请尽量固定文件路径和文件名。本地文件的存储规则由浏览器决定：本轮 Edge 下保存、刷新恢复正常，但换浏览器、移动或重命名文件后，不保证还能读到原配置；线上网站的数据也不会自动迁移到本地文件。禁止本地存储的浏览器仍会显示会话内使用的提示。部分手机文件预览器不会执行 HTML 脚本，须使用允许打开本地 HTML 的正常浏览器。

### 网站版与开发预览

网站版 `index.html` 请通过 HTTP(S) 静态托管访问，保留它旁边的整个 `assets/` 文件夹。页面运行时不依赖外部字体、图标或 CDN。

本机预览：安装 Node.js 22.13 或更新版本后，在项目目录运行：

```sh
npm start
```

在浏览器中访问终端显示的本机地址，默认是 `http://127.0.0.1:4175`。预览服务仅允许读取首页、头像及前端资源。网站源码使用 ES module，受浏览器跨源规则限制；**需要双击运行时请打开 `qingzheng-offline.html`，而不是 `index.html`**。已有线上网站的数据也不会自动出现在本机地址，地址或端口变化会使用不同的本地存储空间。

### 浏览器范围

建议基线为 Chrome / Edge 120+、Safari / iOS Safari 16.4+、Firefox 113+，以及相应较新的 Android System WebView。功能使用 ES module、`replaceChildren`、`inert` 和 `Array.at`，装饰使用 `color-mix`、CSS 遮罩等；这不是仅由 Node.js 的 `engines` 字段决定的范围。不再依赖 ES2023 的 `findLast`。

2025–2030 年农历使用随站数据；其他年份需要浏览器的 Intl 中文历法支持，不可用时省略农历，不影响排班。内嵌浏览器还需允许脚本、同源资源和本地存储；宿主禁用存储时只能会话内使用。本轮真实浏览器检查使用本机 Edge，并不等于已经逐一验证上述最低版本或所有 App 宿主。

## 排班与方案

- 点击「排班设置」，选择周期起始日期，再用空格填写重复的班次顺序，例如 `白班 夜班 休息 白班 夜班 休息 休息 休息`。起始日期对应第一个班次。
- 每个班次可以设置颜色、工作或休息属性，以及上下班时间。名称不能包含空格，最多 40 个字符。
- 添加班次直接在设置页填写「新班次名称」，再点击「添加班次」或按回车。删除班次和删除方案都使用页面内确认，不调用原生 `prompt` / `confirm`。在设置中取消删除会回到原草稿；确认删除也要再保存设置才影响实际排班。
- 下班时间早于或等于上班时间时，视为次日下班。也可以手动勾选「跨日」；例如 09:00 至次日 17:00 会计为 32 小时。
- 修改期间使用独立草稿；「取消」、关闭弹窗或按 Esc 都会放弃修改。添加、删除班次不会丢失其他尚未保存的输入。
- 在周期中直接输入新名称时，第一次保存会补充对应的时间定义，确认后再次保存才会应用。
- 「保存方案」会打开页面内的命名窗口，确认后记录当前周期起始日期、周期和班次定义，不再依赖部分应用内浏览器可能禁用的系统输入框。空名称、超长名称或重名会在窗口内提示；取消、关闭或按 Esc 不保存。顶部方案按钮用于切换，旁边的 × 用于删除方案；删除方案保留当前排班。
- 保存方案和编辑排班使用纯色、无动效的独立输入页，暂时隐藏日历与装饰，并暂停时钟、倒计时和人物文案的后台刷新。进入后再点击输入框唤起键盘，滚动交给浏览器处理，不监听输入法尺寸、不强制调整窗口或反复聚焦。保存或取消后恢复日历的原滚动位置，并立即更新实时信息。
- 日历显示班次名称、农历及节气，点击日期可查看详细安排。年度总览可以点击月份跳转，点击其中的小日期也可以打开详情。
- 侧栏显示未来七天；选中日期后，侧栏切换为该日详情，关闭后恢复七天安排。年度总览默认折叠，可通过顶部「年度总览」或页面下方的展开入口查看。
- 月度统计跟随当前查看的月份；计划工时按班次开始日期计入当月，保留小数，不等同于考勤记录或工资核算。
- 仍在进行的昨日跨日班次会显示「昨日班次」，周期位置随实际班次起始日期计算；到达下班时间后自动切换。

键盘：← / → 切换月份，T 回到今天，Esc 关闭弹窗或详情。年月范围为当前年份前后各一年，按钮和快捷键使用同一边界。

顶部月亮 / 太阳按钮用于手动切换主题，旁边的时钟按钮启用昼夜自动模式：设备本地时间 07:00–19:00 为银昼，其余时间为蓝夜。已有手动偏好会保留，自动模式也会被记住。首次绘制前就应用主题，避免深色页面闪白。

人物呼吸、饰环旋转、冰晶或气泡浮动、星点闪烁、水波移动和进度扫光已改为静态装饰，页面入场与弹窗不再播放动画。保留切月、日期详情和人物点击时的短暂操作反馈；输入页内的动画、过渡、模糊和阴影均关闭。系统设置了「减少动态效果」时，移动反馈也关闭，功能保持可用。

## Q 版小陪伴

- 银昼显示用户提供的银白大肥龙，文案使用灰紫色；蓝夜显示深蓝大肥鱼，文案使用雾蓝色。原图保留透明通道，不替换顶部立绘。
- 点击人物，在该角色的六条轻松短句和当前排班的一条简要信息之间交替切换。短句打乱顺序，一轮内不重复；不会自动轮播或弹出通知。
- 排班提示包括距离下班、距离下次上班、明天的班次与开工时间、距离下个休息日等，每次只说一条。倒计时显示到分钟，不到一分钟时明确标注；时间分别用青蓝 / 暖金色加粗。
- 信息与当前配置、切换后的方案、实际日期和上下班边界同步，昨日跨日班结束前仍按该班计算。查看其他月份不改变实时提示。纯休息周期不会编造下次上班时间。
- 常规桌面为月历旁的独立小角落；手机与平板放在月历上方。只有宽度至少 2070 px、且高度至少 600 px 的屏幕，才放入页面右下方空白边缘悬浮，不遮挡内容。可用「收起 / 聊两句」折叠气泡，再点人物也能展开。
- 人物点击时轻弹并闪出小星光，支持 Enter / Space。开启减少动态效果后不播放这些动画。自动倒计时不会反复打断屏幕阅读器。

## 本地数据

配置和方案只保存在当前浏览器、当前站点的本地存储中，不上传到服务器，也没有账号或设备同步。清除站点数据会清除这些配置。浏览器禁止存储或容量不足时，页面会明确提示，此时仍能在当前会话中使用。页面内命名窗口能避开原生输入弹窗限制，但不能绕过宿主应用对本地存储的禁用或清理；这种情况下不会将临时保存误报为持久保存成功。

新版读取旧版的 `qingzheng-anchor`、`qingzheng-cycle`、`qingzheng-shift-defs` 和 `qingzheng-presets`。保存排班后使用单条 `qingzheng-config` 记录，避免分次写入造成部分保存。旧的配置键保留，不主动删除。损坏的 JSON、空周期或无效日期不会阻止页面启动。

## 农历、节气和节日

2025–2030 年农历月首和 144 个节气日期来自[香港天文台公历与农历对照表](https://www.hko.gov.hk/sc/gts/time/conversion.htm)，离线存放在 `assets/calendar-data.js`。日期按 UTC+8 的中国历法理解，并按年使用对应的表，不会拿 2026 年的节气日期代替其他年份。

已覆盖年份使用月首表推导农历，避免不同浏览器内置历法对 2027 年春节等日期的计算差异。超出覆盖年份时，农历使用浏览器的 Chinese Calendar 支持作为回退，未另行逐日核验；没有对应年份数据的节气不显示。

节日标记仅显示节日本身的日期，不推测未来法定假期、连休或调休安排。实际工作和休息始终由用户设置的排班周期决定。

日期格会以彩色标签和小插画标出元旦、除夕、春节、元宵节、清明、劳动节、端午节、中秋节、国庆节、重阳节：对应庆祝礼花、饺子、灯笼与梅花、花灯与汤圆、柳枝与风筝、齿轮与麦穗、粽叶、月兔与月饼、旗帜、菊花与远山。插画采用细描边与柔和配色，两套主题共用同一组素材和节日颜色。

当天为节日时，今日概览增加节日提示；点击节日日期也可在详情中看到完整名称和插画。同一天遇到两个节日时会保留两者。提示按设备当前日期切换，昨日跨日班次不会影响当天的节日判断。

「未来七天」同样显示对应日期的节日名称和小插画，节日标签放在日期与班次下方；与月历共用历法判断和插画配色，跨月、跨年及午夜更新时保持一致。点击该行仍会打开当天排班详情。

全站功能文字较前版放大，日期格同时增加高度。手机日期格把日期、班次、农历、插画、节日名称分行排布；节日名称允许换行，避免小屏截断。

## 资源与部署

- 修改源码后运行 `npm run build`，一次更新网站版资源哈希和完整离线文件，再运行 `npm run check`。这些命令只供维护者生成新版使用，拿到离线 HTML 的使用者不需要运行任何命令。也可用 `npm run build:offline` 单独重新生成离线版；不要手工修改生成文件。
- 网站版所有 HTML 资源地址、模块导入和 CSS 图片引用使用内容哈希参数。发布时上传首页与整个资源目录即可，不需要外部打包器；生成脚本不会改动图片或历法数据的内容。
- 原仓库的 GitHub Pages 从 `main` 分支根目录发布，网站入口仍是 `index.html`，无需为 ES module 增加服务器运行环境或更换 Pages 配置。`qingzheng-offline.html` 是额外的独立文件，不替换首页，也不会在访问首页时自动下载。网站地址与存储键不变时，已有浏览器配置继续按旧数据兼容规则读取。
- 单文件生成器仅支持本项目当前使用的静态默认/命名导入及常量/函数导出，不是通用 JavaScript 打包器；遇到其他模块语法或循环依赖会报错。`.gitattributes` 固定文本为 LF，避免跨平台换行造成内容哈希或 CSP 校验漂移。
- 头像由 628,341 字节的原图生成 4,052 字节的 WebP；两张 Q 版图由 1,481,186 字节降为 56,124 字节，保留透明通道和原图。只为当前主题设置图片来源；另一主题在第一次切换时才加载，Q 版图另使用懒加载。首屏头像和顶部立绘不盲目懒加载。
- 今日卡片以民用日期、有效班次、跨日状态、周期位置及配置版本作为更新键。每秒仍更新时钟和实际变化的倒计时，不再重复写入静态文案、进度样式和 ARIA；午夜、跨日班结束或修改配置时立即失效更新。
- `_headers` 为 Cloudflare 静态资源提供 CSP、防嵌入、MIME 和权限等安全头，HTML 另带 CSP 元标记；脚本不允许内联代码或 `eval`，样式也不放宽为 `unsafe-inline`。GitHub Pages 不读取 `_headers`，需要宿主或代理配置才能获得其余响应头，尤其是不能通过元标记设置的 `frame-ancestors`。
- 旧 Android 桥仅在宿主显式提供 `window.Android.saveSettings` 时调用，已隔离在适配器内。桥接失败不影响网页保存；普通浏览器不依赖它。
- `.assetsignore` 供 Cloudflare 资源部署排除本地测试、备份、工作流、未压缩原图及离线 HTML，不是 Git 忽略规则，GitHub Pages 也不会读取它。离线文件供本地打开或单独分发；GitHub Pages 可将其作为额外文件发布，使用它自带的哈希 CSP。其他托管平台若给离线文件施加网站版只允许外部脚本的响应头，应排除该文件或单独配置策略，不能直接沿用网站版 CSP。
