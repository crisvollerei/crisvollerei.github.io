# 清蒸排班表

一个完全在浏览器中运行的个人轮班日历。支持自定义排班周期、班次时间、跨日班、方案切换、月度统计和年度总览，不需要后端或账号。

[在线使用](https://crisvollerei.github.io/)

## 功能

- 自定义周期起始日期和班次顺序，为每个班次设置颜色、工作 / 休息属性及上下班时间。
- 月历展示班次、农历、节气与节日，点击日期查看详情；支持按钮、键盘和手机左右滑动切月。
- 今日概览显示当前班次、周期进度、下次休息及上下班倒计时，支持昨日跨日班次。
- 月度概览汇总各类班次、计划工时和工作日占比；未来七天与年度总览提供近期和长期视图。
- 保存多套排班方案，在同一浏览器中切换使用。
- 「银昼 / 蓝夜」两套主题，支持手动切换或按设备本地时间自动切换。
- 大肥龙 / 大肥鱼 Q 版陪伴，提供简短关心、轻松闲聊和实时排班提示。
- 所有运行资源保存在项目内，无外部字体、图标或 CDN 依赖；提供完整单文件离线版。

## 使用方式

### 在线或本机预览

网站版以 `index.html` 为入口，通过 HTTP(S) 静态托管访问，并保留整个 `assets/` 目录。

本机预览需要 Node.js 22.13 或更新版本。在项目目录运行：

```sh
npm start
```

打开终端显示的地址，默认为 `http://127.0.0.1:4175`。运行网站和预览服务不需要安装依赖。

### 单文件离线版

使用正常浏览器打开根目录的 `qingzheng-offline.html`。脚本、样式、人物图片与装饰均包含在这个文件中，可以单独复制使用，无需 Node.js、服务器或联网。

请勿直接双击网站版的 `index.html`：它使用 ES module，需要通过 HTTP(S) 加载。部分手机文件预览器不执行 HTML 脚本，离线版也需要交给支持本地 HTML 的浏览器打开。

本地文件的存储规则由浏览器决定。请尽量固定文件路径和文件名；更换浏览器、移动或重命名文件后，可能无法读取原配置。在线版、离线文件及不同本机地址之间不会自动同步数据。

## 排班与导航

打开「编辑排班」，选择周期起始日期，以空格填写重复的班次顺序，例如：

```text
白班 夜班 休息 白班 夜班 休息 休息 休息
```

起始日期对应周期中的第一个班次。班次名称不能包含空格，最多 40 个字符。添加、删除和编辑期间使用独立草稿，保存才会应用；取消、关闭或按 Esc 会放弃草稿。周期中填写了尚未定义的名称时，页面会先补充时间定义，供确认后再次保存。

下班时间早于或等于上班时间时，视为次日下班；也可以手动指定跨日。例如 09:00 至次日 17:00 计为 32 小时。月度计划工时按班次开始日期计入当月，保留小数，不等同于考勤或工资核算。

「保存方案」记录当前周期起始日期、班次顺序和定义。顶部方案按钮用于应用方案，旁边的 × 用于删除方案；删除方案不改变当前排班。名称校验、添加和删除确认均在页面内完成。

保存方案和编辑排班使用无动效的独立输入页，暂时隐藏日历与装饰，并暂停后台实时刷新。点击输入框后唤起键盘，保存或取消后恢复日历原滚动位置。

- 月历日期区域向左滑看下个月，向右滑看上个月；上下滚动、双指缩放和短距离误触不切月。
- 点击月份标题选择年月，点击「今天」返回当前日期。
- 键盘 ← / → 切月，T 返回今天，Esc 关闭弹窗或日期详情。
- 选中日期时，详情替换未来七天；关闭详情后恢复七天安排。
- 年度总览默认折叠，可点击月份或其中的日期回到月历。导航范围为设备当前年份前后各一年。

## 主题与陪伴

银昼使用银白、灰紫和冰蓝，蓝夜使用深海蓝、雾蓝和暖金；视觉规则与素材结构见 [设计说明](DESIGN_NOTES.md)。太阳 / 月亮按钮手动切换主题，时钟按钮启用自动模式：设备本地时间 07:00–19:00 为银昼，其余时间为蓝夜。

大肥龙与大肥鱼各有 32 条短句：大肥龙偏可靠、稍微嘴硬，关心藏在提醒和肯定里；大肥鱼偏贪吃、爱摸鱼，用轻松的打工人语气陪你歇一会儿。性格只作轻微区分，不影响排班信息。

点击人物在闲聊与排班提示间交替。闲聊打乱顺序，一轮内不重复，不自动轮播或弹出通知；排班提示每次只显示下班倒计时、下次上班、明日班次或下次休息中的一条，并跟随实际配置、日期和班次边界更新。

陪伴区可收起，再点人物可展开并换句。换句不改变人物与下方内容的位置；超长自定义名称可在留言内滚动，支持 Tab 聚焦及方向键、Page Down、End 阅读。点击有短暂轻弹和星光，实时倒计时不反复打断屏幕阅读器。

场景中的菱形、星芒和光点沿细线轨道缓慢行进，菱形另有独立自转。装饰离屏、页面后台或弹窗开启时暂停；输入页关闭动效。系统启用「减少动态效果」时，持续动画与移动反馈均关闭，功能保持可用。

## 数据与隐私

配置和方案仅保存在当前浏览器、当前站点的本地存储中，不上传服务器，没有账号或跨设备同步。清除站点数据会清除配置。存储被禁用或容量不足时，页面明确提示只能在当前会话中使用。

配置使用 `qingzheng-config`，同时兼容 `qingzheng-anchor`、`qingzheng-cycle`、`qingzheng-shift-defs` 和 `qingzheng-presets` 等已有记录；读取兼容数据不会主动删除旧键。损坏的 JSON、空周期或无效日期不会阻止页面启动。

## 农历、节气与节日

2025–2030 年农历月首和 144 个节气日期来自[香港天文台公历与农历对照表](https://www.hko.gov.hk/sc/gts/time/conversion.htm)，随项目保存在 `assets/calendar-data.js`，按 UTC+8 中国历法理解。超出覆盖年份时，农历依赖浏览器的 Intl Chinese Calendar 支持，不可用时省略；缺少年度数据的节气不显示。

节日装饰覆盖元旦、除夕、春节、元宵、清明、劳动节、端午、中秋、国庆和重阳，同日重合时保留两者。月历、今日概览、未来七天与日期详情共用节日判断。节日只标识实际日期，不推测法定假期、连休或调休；工作与休息始终以个人排班为准。

## 维护与部署

网站运行没有生产依赖。开发检查使用 JSDOM：

```sh
npm ci
npm run build
npm run check
```

`npm run build` 更新资源内容哈希及 `qingzheng-offline.html`；不要手工修改离线生成文件。`npm test` 运行回归检查，`npm run check` 还校验资源版本及离线文件与源码是否同步。GitHub Actions 在 push / PR 时运行检查。

GitHub Pages 使用 `main` 分支根目录，入口为 `index.html`，无需服务器运行时。其他静态托管也可使用同一入口和 `assets/` 目录；已有配置能否延续取决于网站地址与存储空间是否保持一致。

页面使用严格 CSP，不允许任意内联脚本或 `eval`；离线版使用自身脚本和样式的精确哈希。`_headers` 适用于支持该文件的 Cloudflare 托管，GitHub Pages 不读取它。其他平台若给离线 HTML 添加响应头，需使用与该文件相容的 CSP，而非直接套用网站版外部脚本策略。

`.assetsignore` 控制 Cloudflare 资源打包，排除开发工具、说明、未压缩原图和离线文件；它不是 Git 忽略规则，GitHub Pages 也不读取它。本机备份、检查产物和依赖分别通过 `.gitignore` 排除。

建议使用 Chrome / Edge 120+、Safari / iOS Safari 16.4+、Firefox 113+ 或相应较新的 Android System WebView。内嵌浏览器仍需允许脚本、同源资源和本地存储。可选 Android 桥位于 `assets/integrations.js`，普通浏览器不依赖它。
